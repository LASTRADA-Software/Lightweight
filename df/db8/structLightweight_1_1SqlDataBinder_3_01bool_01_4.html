Detailed Description

Binds a bool as SQL_BIT. A read goes through a value the statement stages, never straight into the bool, and applies the rule of the block prefetch, so a read gives the same with and without it: a number reads 0 as false and 1 as true, -1 as true where the driver reports a boolean true so (SqlQueryFormatter::BooleanTrueMayBeMinusOne, PostgreSQL), and fails with SQLSTATE 22003 otherwise; a floating-point number reads as its integral part where it is in [0, 2). The C type follows the column's described SQL type: SQL_C_SBIGINT for an integer or bit column (the drivers write the number itself, where SQL_C_BIT gets PostgreSQL's low byte and SQLite's "positive is 1"), SQL_C_DOUBLE for a floating-point or decimal column (SQLite answers a fraction through SQL_C_SBIGINT as NULL), and SQL_C_BIT for text and any other type (the drivers parse 'true' only there). A NULL read into a bound bool sets it to false, as the block prefetch does.
