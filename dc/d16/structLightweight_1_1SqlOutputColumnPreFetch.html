Detailed Description

A step a binder plans to run before every fetch into the output column it binds.

Plain data rather than a type-erased callable, so planning one never allocates, not even when a column is bound anew for every row. run receives the step itself (so it can update boundData and boundSize) and the statement handle the column is bound on.
