Detailed Description

template<typename T, SQLSMALLINT TheCType, SQLINTEGER TheSqlType, typename WideType, SQLSMALLINT WideCType, auto TheColumnType>
struct Lightweight::SqlStagedIntegerDataBinder< T, TheCType, TheSqlType, WideType, WideCType, TheColumnType >

Binds an integer type whose C type not every driver converts over the type's full range.

Where SqlQueryFormatter::ConvertsNarrowIntegerCTypes holds (SQL Server, PostgreSQL) it binds in place exactly like SqlSimpleDataBinder. Where it does not (SQLite, whose driver stores an SQL_C_STINYINT -1 as 255 and an SQL_C_ULONG above INT32_MAX as negative), each value goes through a WideType staging copy bound as WideCType: an input parameter takes one of the statement's parameter staging slots, a column-wise batch one buffer for the whole column, an output column the statement's staging slot of that column (reused when the column is bound again) plus a copy per row, and a GetColumn a stack copy. A staged value outside T's range fails the read with 22003, and a NULL resets a bound T to 0, as the block prefetch does. Deciding between the two costs one virtual call per bind or read.

staged, a value read through the wider C type, as T. Accepts T's range and the form earlier versions stored on SQLite, which bound TheCType in place: the same bits read with the other signedness (an int8_t -1 stored as 255, a uint32_t 4294967295 stored as -1). The block prefetch applies the same decision on a dialect that stages (see SqlStatement::ConvertCell).
