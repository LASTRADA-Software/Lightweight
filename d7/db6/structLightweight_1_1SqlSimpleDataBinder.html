Template Parameters
TheColumnSizeThe ODBC column size to bind with. Zero is correct for the fixed-width numeric types, whose size the driver derives from the C type, but a character SQL type takes its length in characters here and SQL Server rejects a zero there with HY104.

Binds a contiguous (column-wise) or row-strided (row-wise) array of values as an input parameter.

Parameters
indicatorsOptional per-row NULL/length indicator array. Passed straight to ODBC as the StrLen_or_IndPtr; defaults to nullptr (no NULLs). For row-wise binding the driver strides it by the statement's SQL_ATTR_PARAM_BIND_TYPE, matching the value stride.
