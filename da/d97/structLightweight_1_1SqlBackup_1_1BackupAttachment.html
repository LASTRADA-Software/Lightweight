Detailed Description

A caller-supplied file that a backup stores in its archive next to the table data.

The archive holds it as attachments/<name> and lists it in checksums.json; restore ignores it.

◆ name

std::string Lightweight::SqlBackup::BackupAttachment::name {}

The relative path within attachments/ as UTF-8, with / separating folders (e.g. notes/readme.txt). It must be well-formed UTF-8 without control characters, must not be empty, start or end with /, contain a backslash or a colon, or have an empty, . or .. path segment. Ignoring ASCII letter case, it must differ from every other attachment's name and must not be the folder of another one.
