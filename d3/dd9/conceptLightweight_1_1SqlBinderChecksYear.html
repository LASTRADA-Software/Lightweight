Detailed Description

Whether the binder of T can tell, before anything is bound, that a value of T holds a date or timestamp whose year cannot be written (see detail::IsWritableYear()): the dates themselves and the wrappers that bind through them. A batch that executes row by row checks every row through it first, so that no row is stored when one would be refused; a type without it costs nothing.
