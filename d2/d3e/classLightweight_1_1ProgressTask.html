Detailed Description

Progress of one task, which the library reports and a host (a CLI, a GUI) renders.

Tasks nest: a task opens sub-tasks for its parts, and destroying a task marks it finished. A total of 0 makes a task indeterminate: the host shows that it runs and for how long, not how far it got. The host implements this interface and the library only calls it, possibly from a worker thread, one task tree at a time. New virtual functions are only ever appended at the end.
