Detailed Description

Binds a single char as a one-character CHAR(1) value.

Unlike the numeric primitives, char maps to a character type (SQL_C_CHAR / SQL_CHAR), whose ODBC contract differs from fixed-width data in three ways, each of which this binder honours:

  • On input, the column size is the length in characters and must not be zero (MS SQL Server rejects zero with HY104 "Invalid precision value").
  • On input, the value is not NUL-terminated, so its length must be passed through the indicator — without one the driver reads the value as a NUL-terminated string, past the end of the char.
  • On output, the driver NUL-terminates what it writes, so the buffer needs room for one more byte than the value; a one-byte buffer receives nothing.
