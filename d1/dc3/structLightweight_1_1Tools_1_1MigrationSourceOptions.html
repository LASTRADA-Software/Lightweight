◆ timestamp

std::string Lightweight::Tools::MigrationSourceOptions::timestamp

The YYYYMMDDHHMMSS timestamp that identifies the migration. Emitted verbatim as the first argument of LIGHTWEIGHT_SQL_MIGRATION, so the caller owns the format; FormatMigrationTimestamp produces the canonical shape.

◆ includePluginEntryPoint

bool Lightweight::Tools::MigrationSourceOptions::includePluginEntryPoint = false

When true, the file also carries LIGHTWEIGHT_MIGRATION_PLUGIN(). Exactly one translation unit per migration plugin may define it, so this defaults to off: a generated migration usually joins an existing plugin that already has one.
