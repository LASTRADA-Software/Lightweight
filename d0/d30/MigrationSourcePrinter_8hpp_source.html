16/// @brief Knobs controlling how a migration source file is emitted.
17///
18/// @ingroup SqlMigration
19struct MigrationSourceOptions
20{
21 /// The `YYYYMMDDHHMMSS` timestamp that identifies the migration. Emitted verbatim as
22 /// the first argument of `LIGHTWEIGHT_SQL_MIGRATION`, so the caller owns the format;
23 /// `FormatMigrationTimestamp` produces the canonical shape.
24 std::string timestamp;
25
26 /// Human-readable migration title, emitted as the macro's second argument.
27 std::string title;
28
29 /// When true, the file also carries `LIGHTWEIGHT_MIGRATION_PLUGIN()`. Exactly one
30 /// translation unit per migration plugin may define it, so this defaults to off:
31 /// a generated migration usually joins an existing plugin that already has one.
32 bool includePluginEntryPoint = false;
33
34 /// Optional provenance banner emitted as a comment above the migration, e.g. the
35 /// connection the diff was taken against. Empty means no banner.
36 std::string provenance;
37};

39/// @brief Emits a compilable `.cpp` migration source file for @p plan.
40///
41/// The body is the migration DSL spelling of @p plan: `CreateTable`, `AlterTable`,
42/// `CreateIndex`, `DropTable` and `RawSql` elements each render as the fluent call that
43/// would rebuild them. A column declaration that the fluent shorthands cannot express
44/// losslessly (a default value, a composite primary-key position, a GUID primary key)
45/// falls back to the `Column(SqlColumnDeclaration { ... })` overload rather than silently
46/// dropping the attribute.
47///
48/// Data plan elements (INSERT / UPDATE / DELETE) are not schema changes and are emitted as
49/// a visible `// NOTE:` comment instead of code — autogenerate produces DDL only, and a
50/// silently missing data step would be worse than an obvious one.
51///
52/// An empty @p plan yields a valid migration with an empty body, which is the scaffolding
53/// mode: a correctly-timestamped file for the author to fill in.
54///
55/// @param options Timestamp, title and emission knobs.
56/// @param plan The plan elements to spell out, in replay order.
57/// @return The full contents of the `.cpp` file, newline-terminated.
58[[nodiscard]] std::string PrintMigrationSource(MigrationSourceOptions const& options,
59 std::span<SqlMigrationPlanElement const> plan);
60
61/// @brief Formats a time point as a `YYYYMMDDHHMMSS` migration timestamp in UTC.
62///
63/// UTC rather than local time so that two authors in different zones cannot produce
64/// timestamps that order differently from the wall-clock order in which they wrote them.
65///
66/// @param when The instant to format.
67/// @return The 14-digit timestamp.
68[[nodiscard]] std::string FormatMigrationTimestamp(std::chrono::system_clock::time_point when);
69
70/// @brief Turns a free-form migration title into a filename-safe `lower_snake` slug.
71///
72/// Alphanumerics are lower-cased and kept, every other run of characters collapses to a
73/// single underscore, and leading/trailing underscores are trimmed. A title with no usable
74/// characters yields `"migration"` so the caller always has a filename.
75///
76/// @param title The human-readable title.
77/// @return The slug.
78[[nodiscard]] std::string SlugifyMigrationTitle(std::string_view title);
